# President of Nigeria: The Republic — Web App v0.1

Original mobile-first political decision simulation. Scenarios and statistics are fictional game mechanics, not live government data.

## Free deployment with GitHub Pages
1. Create a **public** GitHub repository.
2. Upload the **contents of this folder** to the repository root. `index.html` must be at the root, not nested in another folder.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then tap **Save**.
6. Wait a few minutes and open the website URL shown on the Pages screen.

Official instructions: https://docs.github.com/en/pages/quickstart

## Add to iPhone Home Screen
1. Open the published HTTPS URL in Safari.
2. Tap Share (square with an upward arrow).
3. Choose **Add to Home Screen**, then tap **Add**.

The game saves to local browser storage on that device. Clearing Safari website data can erase saves. The web app can cache core files for basic offline use after the first successful visit.
